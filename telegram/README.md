# FLOWBOT Telegram

Payments use Telegram Stars (XTR) for digital services.

Required Vercel variables:
- TELEGRAM_BOT_TOKEN
- TG_BOT_USERNAME
- TG_PLAN_1M_STARS
- TG_PLAN_2M_STARS
- TG_PLAN_3M_STARS
- TG_PLAN_6M_STARS
- TG_PLAN_12M_STARS

1 month is recurring. 2/3/6/12 months are one-time access packages.

Webhook: /api/telegram/webhook
